# US-13 — Filter tasks by status from the list

| Field | Value |
|---|---|
| **ID** | US-13 |
| **Layer** | Frontend |
| **Actor** | Task owner |
| **Consumes endpoint** | `GET /api/tasks?status={status}` — combinable with `search` (US-07) |
| **Spec user story** | Story 7 — Focus on one state of work (P3) |
| **Priority** | P3 |

## Description

As the task owner, I want to filter my list to a single state so that I can focus on what is still
to do, what is under way, or what I have finished. The filter works together with the search box
rather than replacing it.

## Acceptance criteria

- **AC-13.1** — A status filter control is available above the list, offering Todo, InProgress,
  Done and an "All" option.
- **AC-13.2** — "All" is the initial selection and shows tasks in every state.
- **AC-13.3** — Choosing a state narrows the list to that state.
- **AC-13.4** — Filtering is performed by the server through the list request, not in the browser.
- **AC-13.5** — **The filter and the search box combine.** With both active, only tasks satisfying
  both are shown.
- **AC-13.6** — Changing the filter does not clear the search term, and changing the search term
  does not reset the filter.
- **AC-13.7** — A filter with no matching tasks shows an explanatory empty state naming the state
  filtered on.
- **AC-13.8** — Returning to "All" restores the unfiltered list.
- **AC-13.9** — State labels read naturally — "In Progress", not "InProgress".
- **AC-13.10** — An active filter survives a create, edit or delete, and a task edited out of the
  filtered state disappears from the current view.

## Traceability

**Satisfies**: FR-019, FR-020, FR-021, FR-027

**Depends on**: US-07, US-08

**Verified by success criteria**: SC-006, SC-008

## Out of scope

Server-side filtering itself (US-07). Filtering by importance or due date. Selecting several
states at once. Saving the filter between sessions.

## Definition of done

Verified in the browser across all four combinations of search and filter, plus an empty filtered
result and a return to "All".
